# IP26-MicroVolunteer-Frontend
Acest repozitoriu contine aplicatia client (Front-end) pentru platforma Micro-Volunteer Crisis Router. 

## Despre Proiect
Scopul acestui proiect este construirea unei platforme care sa conecteze persoanele ce au nevoie de ajutor rapid, local, cu voluntari din proximitate capabili sa rezolve sarcini mici in decurs de cateva minute [2]. Aplicatia permite utilizatorului sa ceara o favoare si sa primeasca ajutor in contexte precum traduceri, livrari rapide, ghidaj local sau nevoi de zi cu zi [2].

## Tehnologii folosite
* React
* TypeScript

## Cum sa pornesti proiectul local
Pentru a rula aceasta aplicatie pe calculatorul tau, asigura-te ca ai Node.js instalat, apoi urmeaza acesti pasi:

1. **Instalare dependinte:**
   Ruleaza comanda `npm install` in terminalul din folderul proiectului.
2. **Pornire server de dezvoltare:**
   Ruleaza comanda `npm run dev` (sau `npm start`) pentru a deschide aplicatia in browser.
